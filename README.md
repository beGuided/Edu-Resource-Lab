# Edu Resource Lab

## Overview

**Edu Resource Lab** is an educational resource platform designed to help students in higher institutions access learning materials easily. The platform provides downloadable course resources, study materials, and helpful links that support students in preparing for their courses and improving academic performance.

The system includes a content management system (CMS) and an administrative dashboard that allows administrators to upload, manage, and organize educational resources efficiently.

---

## Features

- Resource download system for students
- Content Management System (CMS)
- Administrative dashboard for managing resources
- Responsive user interface
- Dark mode support
- Organized learning materials and helpful external resource links

## Installation

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/beGuided/edu-resource-lab.git
```

### 2. Move the project to your local server

Place the project folder inside your server directory.

Example for WAMP:

```
C:\wamp64\www
```

### 3. Setup the database

1. Open **phpMyAdmin**
2. Create a new database
3. Import the provided `.sql` file from the project folder

### 4. Start your local server

Ensure **Apache** and **MySQL** are running.

### 5. Run the project

Open your browser and visit:

```
http://localhost/edu-resource-lab
```
